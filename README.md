# ozmenAgency — Professional Digital Agency

*[Read in Turkish / Türkçe Oku](#türkçe-versiyon)*

[![ozmenAgency](https://image.thum.io/get/width/1200/crop/800/https://ozmenmedia.momez.co)](https://ozmenagency.com)

**ozmenAgency** is a creative digital agency offering professional social media management and consulting services. This project is a dynamic, animated, and interactive landing page website showcasing the agency's services, client success stories, and vision.

## 🚀 Live Demo
You can view the live site at **[ozmenagency.com](https://ozmenagency.com)**.

## ✨ Features
- **Dynamic Animations:** Fluid, scroll-triggered page transitions developed using the GSAP (GreenSock) library.
- **3D Visual Effects:** Interactive 3D animations designed using the OGL library.
- **Multilingual Support:** Fully supported English (`en.html`) and Turkish (`index.html`) versions.
- **Responsive Design:** Flawless appearance fully optimized for mobile, tablet, and desktop devices.
- **WhatsApp Integration:** An optimized floating WhatsApp contact button for users to contact the agency directly.

## 🛠 Technologies Used
- **HTML5 & CSS3:** Modern, clean, and semantic structure.
- **Vanilla JavaScript:** Modular and high-performance interaction management.
- **GSAP & ScrollTrigger:** Scroll-based professional animations.
- **OGL (WebGL):** Lightweight and high-performance 3D rendering.

## 📂 File Structure
- `en.html` — Home page (English version)
- `index.html` — Home page (Turkish version)
- `style.css` — Global styling and design codes adhering to modern UI/UX rules
- `script.js` — Interactions, GSAP animations, and other logical operations
- `img/` — Assets used in the project (logos, client avatars, mascot, etc.)
